Architecture

How FlowPass Works

A seamless in-memory RPC hook executing at document_start.

1

Page Navigation

You open flow.google.com. The browser initiates standard resource loading.

2

MAIN World Hook

FlowPass injects an in-memory interceptor at document_start directly into the page context.

3

RPC Adaptation

Google sends batchexecute calls. FlowPass intercepts the payload and sets regional eligibility flags.

4

Smooth Access

The web app renders the full workspace, seamlessly bypassing the /unsupported-country redirect.

Quick Start

Install In Under 60 Seconds

Compatible with Chrome, Brave, Edge, Opera, Arc, and Vivaldi.

1

Download Extension Package

Download the latest zip package from GitHub Releases or clone the repository:

git clone https://github.com/zephinax/flowpass.git
2

Open Extensions Manager

In your Chromium browser address bar, open the extensions management page:

chrome://extensions

For Brave: brave://extensions • Edge: edge://extensions

3

Enable Developer Mode & Load Unpacked

Toggle Developer mode in the top-right corner, then click Load unpacked and select your unzipped flowpass folder.

4

Pin & Open Google Flow

Pin FlowPass in your extensions toolbar. Click the icon to verify the status shows ACTIVE, and navigate to flow.google.com.

FAQ

Frequently Asked Questions

Does this modify my Google account settings or country?
No. FlowPass operates purely in client-side volatile memory. It does not alter your Google account profile, Play Store region, billing address, or account settings.
Do I need an active VPN connection?
FlowPass removes the need for region-specific VPN routing to access Google Flow. All regional payload adaptation happens inside your browser sandbox.
Is FlowPass safe and private?
Yes. FlowPass contains zero analytics, zero external API connections, and zero tracking code. The source code is completely open for audit on GitHub.
What permissions does the extension require?
FlowPass requests minimal permissions: only scripting and flow.google.com/* host permission. It has no access to any other websites or tabs.
